## 五、避坑清单

1. **不要买三色/四色屏**（黑/白/红）。粒子体系不同，快刷表现极差。
2. **4.2" 模块的控制器有多个版本**：UC8176 / SSD1619 / UC8276，LUT 寄存器不同。买页面明确写型号的，到货先用厂商例程确认。
3. **便宜的 "N16R8" 可能是 N8R2**：收货后跑 `esptool.py flash_id` 核对 Flash 和 PSRAM 大小。
4. **电池必须有保护板**，JST 插头注意正负极（不同厂家红黑顺序可能相反，接反会烧板）。
5. **杜邦线看屏幕接口**：微雪模块是**排母** → 买**公对母**；DIY MORE 那类通用模块是**公排针** → 买**母对母**。开发板这边 DevKitC-1 是公排针。
6. **逻辑分析仪别买 1 MHz 的玩具**，至少 24 MHz、8 通道，能跑 PulseView。
7. **第一块屏别买 4.2"**：先用 1.54" 把波形跑通，再上大屏。
8. **1.54" 有两种分辨率**：`200×200 / SSD1681`（微雪 V2、SmoothEPD/InkBoy 同款）和 `152×152 / SSD1680`（更便宜的通用模块）。两者命令集接近但**面板尺寸不同，公开的高刷 LUT 参数不能直接套用**。优先买 200×200；买 152×152 也能练手，但 M1 的预算和波形要自己重新标定。
9. **排针可能没焊**：便宜的通用模块只留 8 个过孔。没有烙铁就买"已焊排针"版本，或者先补一把烙铁。

## 六、到货验收（10 分钟做完）

```bash
# 1. 板子
esptool.py --chip esp32s3 flash_id          # 看 Flash 容量
esptool.py --chip esp32s3 chip_id           # 确认型号

# 2. 屏幕：先跑厂商例程全刷一张测试图
#    能出图 → 接线对；颜色反 → LUT 极性反；半边灰 → 供电不足

# 3. 逻辑分析仪：抓 CS/DC/DIN 三根线，确认 0x12（复位）、0x32（LUT）时序
```
