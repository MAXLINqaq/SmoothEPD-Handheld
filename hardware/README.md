## 设计约束（先定下来，避免画板时返工）

| 项 | 值 | 来源 |
|---|---|---|
| 主控 | ESP32-S3-WROOM-1-N8R8 | [02 硬件选型](../docs/02-hardware.md) |
| 屏接口 | SPI（M0–M2）/ 16 bit 并口 + TPS65185（M3+） | 同上 |
| 电池 | 3.7 V 单节，1200–2000 mAh | 同上 |
| 充电 | Type-C，TP4056 / ETA6098 | |
| 按键 | 十字 + AB + Start/Select + 2 肩键 + 电源 | |
| 板尺寸 | ≤ 100×70 mm（4.7" 屏） | 屏外形 |

## 注意

- 高压部分（VGH/VGL/±15V）**必须**做好间距与丝印标识，调试时先测电压再接屏；
- 裸屏 FPC 座 0.5 mm 间距，回流焊或热风，手工烙铁基本焊不了；
- 所有 EPD 相关网络加测试点，方便逻辑分析仪抓时序。
